# 🐍 30 Days of Python Practice — Applied Data & Energy Focus

## Overview

This repository documents my **30-day applied Python practice journey**, focused on building **real-world data engineering and data science skills**, not just completing syntax exercises.

The goal is to:
- Strengthen Python fundamentals through **practical problems**
- Develop **engineering thinking** (readability, robustness, reuse)
- Build a public, consistent **learning + portfolio trail**
- Prepare for **open-source contribution** in energy & climate tech domains

This is **not a course repository**.  
This is a **skill acquisition and habit-building project**.

---

## Learning Philosophy

- **WHY before HOW**  
  Every concept is tied to a real data or engineering problem.

- **Application-first**  
  Problems are inspired by:
  - sensor data
  - time-series data
  - configuration handling
  - data validation
  - small utilities used in real projects

- **Engineering clarity over academic perfection**  
  Readable, maintainable, and defensive code is preferred over clever tricks.

---

## What This Repository Contains

Each day focuses on:
- One **core Python concept**
- One **applied problem**
- One **clean, documented solution**

Typical problems include:
- Data validation & cleaning
- Experiment / pipeline utilities
- Configuration & metadata handling
- Time-series processing
- Refactoring bad code into good code
